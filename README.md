# MediaForge

### Полный список функций MediaForge

* **Редактирование фото:**
* Кадрирование, изменение размера (Resize) и повороты.
* Цветокоррекция (яркость, контраст, насыщенность, фильтры).
* Мозаика с выбором размера пикселей (мелкая, средняя, крупная).
* Кисть размытия («водичка») с настройкой толщины и интенсивности.
* AI-удаление фона и объектов.
* Пакетное наложение водяных знаков или логотипов.


* **Редактирование видео:**
* Базовый монтаж (обрезка, склейка нескольких фрагментов).
* Изменение частоты кадров (FPS), разрешения и пропорций (16:9, 9:16).
* Наложение поверхностных элементов (текст, субтитры, графический оверлей).
* Запись экрана, окна или веб-камеры с прямым сохранением в MP4/GIF.


* **Работа с аудио:**
* Извлечение аудиодорожки из видео без перекодирования.
* Обрезка, склейка и нормализация громкости.
* Подавление фонового шума.


* **Всеядный конвертер:**
* **Изображения:** JPG, PNG, WEBP, ICO (мульти-размерные иконки), GIF, TIFF, BMP, HEIC, SVG.
* **Видео:** MP4, MKV, AVI, MOV, WEBM, GIF.
* **Аудио:** MP3, WAV, FLAC, OGG, AAC, M4A.
* **Документы / PDF:** конвертация страниц PDF в JPG/PNG и обратно.


* **Оптимизация и сжатие:**
* Оптимизация размера фото и видео под лимиты мессенджеров (Discord, Telegram, Email).
* Выбор баланса между качеством и целевым размером файла в мегабайтах.


* **Пакетная обработка (Batch Processing):**
* Одновременная конвертация, переименование или сжатие сотен файлов в один клик.


* **Автоматические субтитры (STT):**
* Генерация `.srt` / `.vtt` файлов из речи в видео/аудио через локальные модели.


* **Безопасность и метаданные:**
* Очистка EXIF-данных у фото (удаление геолокации, даты, модели устройства).
* Редактирование ID3-тегов у аудиофайлов (исполнитель, альбом, обложка).


* **Интерфейс и доступность для новичков:**
* Максимально понятный UX: всплывающие подсказки (tooltips) и понятные подписи для каждого элемента.
* Встроенные быстрые инструкции и визуальные гиды по использованию функций.
* Поддержка двух языков: Русский / English с переключателем в один клик.


* **Готовые пресеты:**
* Шаблоны в один клик: «Сделать ICO 32x32–256x256», «Видео для Shorts/Reels», «Сжать до 25 МБ».


* **Системные интеграции и производительность:**
* Поддержка Drag-and-Drop.
* Быстрые действия через контекстное меню Проводника.
* Аппаратное ускорение (GPU NVENC/AMF/QSV) для работы с видео.
* Возможность управления через командную строку (CLI).
